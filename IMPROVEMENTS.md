# Идеи по улучшению мессенджера

Здесь — идеи, как можно развивать проект дальше. Можно брать по одной и внедрять по мере времени.

---

## Удобство и UX

- **Уведомления в браузере** — запрашивать разрешение на Push и показывать уведомление о новом сообщении, когда вкладка не активна.
- **Звук нового сообщения** — короткий звук при получении сообщения (с возможностью отключить в настройках).
- **Индикатор «печатает»** — по WebSocket отправлять событие «user is typing» и показывать под заголовком чата.
- **Прочитано / доставлено** — хранить в БД статус прочтения (прочитано кем и когда), отображать галочки как в Telegram.
- **Поиск по чатам и сообщениям** — строка поиска в списке чатов и поиск по тексту внутри чата.
- **Закреплённые чаты** — возможность закрепить 1–3 чата вверху списка (флаг в БД + сортировка на фронте).
- **Архив чатов** — скрывать чат из списка без удаления (поле `archived` в БД).
- **Ответ на сообщение (reply)** — при ответе цитировать исходное сообщение и хранить `reply_to_id` в БД.
- **Редактирование и удаление сообщений** — API + кнопки «Изменить» / «Удалить» у своих сообщений.

## Безопасность и конфиденциальность

- **End-to-end шифрование (E2E)** — ключи только на устройствах пользователей, сервер хранит только зашифрованный текст (сложнее: обмен ключами, Signal Protocol или упрощённый вариант).
- **Двухфакторная аутентификация (2FA)** — TOTP (Google Authenticator и аналоги) при входе.
- **Выход из всех устройств** — инвалидация всех выданных JWT по кнопке «Выйти везде» (чёрный список токенов или версия пользователя в БД).
- **Ограничение попыток входа** — временная блокировка или капча после N неудачных попыток по логину/IP.

## Медиа и файлы

- **Сжатие изображений на клиенте** — перед отправкой уменьшать размер/качество больших фото (Canvas или библиотека).
- **Превью для видео** — генерировать первый кадр на бэкенде (ffmpeg) или на клиенте и показывать как обложку.
- **Голосовые сообщения** — запись с микрофона (MediaRecorder), отправка файла, воспроизведение в чате.
- **Срок хранения файлов** — автоудаление старых файлов из `uploads/` по политике (например, через 90 дней) или по настройке чата.

## Группы и участники

- **Роли в беседах** — владелец, админ, участник; право добавлять/исключать, создавать темы, удалять сообщения.
- **Приглашение по ссылке** — генерировать одноразовую или ограниченную по времени ссылку для вступления в беседу.
- **Описание и аватар беседы** — поле `description`, загрузка картинки как аватара группы.
- **Упоминания (@username)** — при вводе @ показывать список участников, в сообщении хранить/подсвечивать упоминания.

## Техника и масштаб

- **Пагинация сообщений** — подгружать старые сообщения порциями (limit/offset или cursor), а не все сразу.
- **Офлайн-режим** — кэш последних чатов/сообщений в IndexedDB или localStorage, очередь исходящих при отсутствии сети (background sync).
- **PWA** — `manifest.json`, Service Worker, установка на главный экран телефона как приложение.
- **Тёмная/светлая тема** — переключатель и сохранение выбора в localStorage или в настройках на сервере.
- **Мультиязычность** — вынос строк в JSON/файлы локализации, переключатель языка.

---

## Админ и модерация

- **Админ-панель** — отдельный фронт или раздел для суперпользователя: список пользователей, чатов, возможность бана, просмотр логов.
- **Жалобы** — кнопка «Пожаловаться» на сообщение, очередь жалоб для модератора.
- **Лимиты** — ограничение размера беседы, количества сообщений в минуту для защиты от спама.

---

## Интеграции

- **Экспорт чата** — выгрузка переписки в PDF или TXT.
- **Боты** — отдельный тип участника «бот», который получает сообщения по API и может отвечать (webhook или long polling).

Можно выбрать 2–3 пункта из списка и реализовывать по шагам — так проект будет понемногу расти без перегрузки.

## Что можно добавить дальше

- **Голосовые сообщения** — запись с микрофона (MediaRecorder), отправка как файл, плеер в чате.
- **Сжатие фото** — перед отправкой сжимать изображения на клиенте (Canvas или библиотека).
- **PWA** — `manifest.json` и Service Worker, установка на главный экран.
- **Поиск по чатам** — фильтр по имени в списке чатов на фронте.
- **Вкладка «Архив»** — показывать архивные чаты и кнопку «Вернуть из архива».
- **Галочки «доставлено/прочитано»** — визуально показывать в сообщениях (данные уже есть в API).
- **2FA** — двухфакторная аутентификация при входе.
- **E2E-шифрование** — сквозное шифрование между пользователями (сложнее, нужен обмен ключами).
